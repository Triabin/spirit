# VibeCoding

氛围编程（vibe coding）是一种由人工智能辅助的编程方式，由计算机科学家、OpenAI联合创始人兼特斯拉前人工智能主管Andrej Karpathy明确提出。该方式以开发者向AI提出自然语言需求为核心流程，通过大型语言模型生成代码，在代码能运行时直接应用，出现问题时再通过自然语言反馈要求AI修改。简言之就是，（与AI大模型）聊天写代码。

AI在开发中主要解决的问题：尽管尽量忽略了需求分析和产品设计等流程中的应用，仅从编程开始，它也能在各方面发挥重要作用。

* 自然语言到代码以及各种`agent`的调用
* 解决“一次开发，多端运行”的难题
* 让AI运营以及推广自己（AI生成文案、AI自媒体发布、AI生成视频）
